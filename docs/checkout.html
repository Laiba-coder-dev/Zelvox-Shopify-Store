Checkout is hosted by Shopify

This theme never renders a checkout. The Buy Now and Checkout buttons hand off to Shopify's secure hosted checkout at /checkout.

  • On a real store, this route is served by Shopify — orders, payment and taxes are handled there.
  • There is no fake checkout in this theme, and none should be added.
  • To try the real flow, upload this theme to a Shopify store (or a free Shopify Partners dev store).
